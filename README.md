# BENCHIN
Gnani-powered multilingual speech transcription and evaluation platform

# To run 
Step 1 : Create a virtual environment using 
                    python3 -m venv .venv

Step 2 : Activate the virtual envirnoment using
                    python3 -m venv .venv

Step 3 : Install dependencies 
                    pip install fastapi "uvicorn[standard]" pydantic python-dotenv requests python-multipart

Step 4 : Start the project using 
                    uvicorn app.main:app --reload
